# STM32 智能循迹小车 Web 仿真器 (STM32 Car Simulator)

基于 **STM32 智能循迹小车固件算法与参数** 构建的 Web 仿真器。控制器使用独立 TypeScript 移植，车辆和灰度输入来自简化模型；固件与仿真器须分别验证。2026-11-07 已将固件当前工作树的参数与算法逐项同步到仿真器；2026-11-08 按用户要求给固件 `route.c` 增加“几何节点授权”（算法改动，未改任何参数），并同步到仿真器。`npm run parity` 用相同输入逐帧对比 C 与 TS 的控制输出。

## 🌟 核心特性

1. **固件算法与参数的 TypeScript 移植**：
   - 完整移植 `car_stm32` 核心 C 算法：
     - `gray_sensor.c`：8 路灰度传感器多数滤波投票、连续区域分割与权重位置解算（权重 `[-7, -5, -3, -1, 1, 3, 5, 7]`）。
     - `route.c`：路径规划状态机（`ROUTE_FOLLOW`、`ROUTE_CANDIDATE`、`ROUTE_EXECUTING`、`ROUTE_CLEARING`、`ROUTE_BRAKING`、`ROUTE_RECOVERING`、`ROUTE_FINISHED`）与六边形环岛子状态机（`HEXAGON_OFF`、`ENTERING`、`FOLLOWING`、`EXIT_CANDIDATE`、`EXITING`、`DONE`）。

## 🚀 快速启动

### 1. 安装依赖
```bash
npm install
```

### 2. 启动本地开发服务
```bash
npm run dev
```
启动后终端将输出访问地址（如 `http://localhost:5173/`），在浏览器中打开即可开始仿真！

### 3. 构建发布版本
```bash
npm run build
npm run preview
```

### 4. 回归测试
```bash
npm test              # TS 控制器 / 物理 / 路线契约
npm run parity        # C 固件与 TS 控制器逐帧对比（需要本地固件源码）
npm run parity:legacy # POSE_NAV_ENABLED=0 的纯灰度旧控制器对比
```
`npm test` 覆盖启动确认、三/四/五路平滑分支、满角转向出口与三帧回线、普通失线 400 ms/8 cm 停车、首两弯、Q4→Q6 物理轨迹、六边形入口/逐边/出口，以及新加的电阻图形采样回归。电阻回归（`tests/resistor_artwork.test.ts`）验证 19 个印刷电阻在旋转 0/90°、横向 ±0.4 cm 偏移、前后端帽等情况下分别产生 `0xC3` 双外边与单区宽端帽，并验证 `grayClassify` 将其识别为可跟踪的平行对。

`npm run parity`（`tests/firmware_parity.mjs`）把仿真器产生的同一批 `GrayObservation`、编码器计数与航向喂给**固件当前源码**编译出的 C 控制器，要求路线 FSM 事件、路口计数、失败原因、目标轮速和里程逐帧一致；`npm run parity:legacy` 额外用 `-DPOSE_NAV_ENABLED=0` 编译并跑方案 0–7，覆盖旧灰度控制器的滚动圆弧控制律。这是“固件参数不得改动、仿真器迁就固件”的硬约束回归。仿真器不建模 MPU 俯仰保护、无编码器开环 PWM 模式与实车诊断环形缓冲；这些是硬件/构建变体专属路径，生产配置（编码器 + IMU）不受影响。

2026-11-08 新增的“控制器层几何节点授权”：候选灰度节点确认后，若前视探头与该行已知 waypoint 角点的前后偏差 ≤2.5 cm、横向 ≤12 cm，则该节点直接授权动作，不再依赖可能失效的计数/表长。这样修掉了外框测试圈右上角的冲出赛道：实车/仿真都在右上角只数到 9/11、距离 342.6/370 cm，旧逻辑把它当“路过节点”直行；新逻辑在探头压到角点时正常右转，内置方案 3 的右上角不再冲出赛道（探头压到角点即授权右转）。注意：补回 (245,170)→(245,220) 缺线后，底边多了一个节点，内置表第 3 行 `junction_count=6` 会提前一个节点起转，需要把该行计数重标（仿真里 5 可闭合）；这是路线表参数问题。

## 🎮 操作指南

| 操作 | 对应快捷键 / 按钮 | 功能说明 |
| :--- | :--- | :--- |
| **运行 / 暂停** | `空格键` 或 `▶ / ⏸` | 启动或暂停物理仿真推进 |
| **单步步进** | `⏭ 单步` | 暂停状态下向前单步推进 $5\text{ ms}$（一个控制周期） |
| **复位起点** | `↺ 复位` | 小车瞬间回到初始发车点 $P(0, 110)$ 并朝向正北 |
| **调节倍速** | `0.2x` ~ `10x` | 选择 $0.2\sim 10$ 倍速加速仿真或慢动作分析循迹细节 |
| **画面铺满** | `⛶ 画面铺满` | 视口自动居中且填满当前浏览器窗口 |
| **缩放与平移** | 鼠标滚轮 / 鼠标拖拽 | 自由缩放赛道细节或拖动赛道视角 |
| **上传路径表** | `📁 上传 route_table.c` | 选择本地文件或拖入窗口，一键热替换路径 |
| **切换方案** | 顶部下拉菜单 | 一键在方案 0、1、2、3 之间无缝切换 |
| **显示切换** | 底部右侧复选框 | 勾选/取消勾选“视角跟随”、“尺寸标注”、“元件标记” |
