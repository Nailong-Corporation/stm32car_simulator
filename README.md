# STM32 智能循迹小车 Web 仿真器 (STM32 Car Simulator)

基于 **STM32 智能循迹小车固件算法与参数** 构建的 Web 仿真器。控制器使用独立 TypeScript 移植，车辆和灰度输入来自简化模型；固件与仿真器须分别验证。当前减速距离口径、元件采样等已知差异见下方回归测试说明。

---

## 🌟 核心特性

1. **固件算法与参数的 TypeScript 移植**：
   - 完整移植 `car_stm32` 核心 C 算法：
     - `gray_sensor.c`：8 路灰度传感器多数滤波投票、连续区域分割与权重位置解算（权重 `[-7, -5, -3, -1, 1, 3, 5, 7]`）。
     - `route.c`：路径规划状态机（`ROUTE_FOLLOW`、`ROUTE_CANDIDATE`、`ROUTE_EXECUTING`、`ROUTE_CLEARING`、`ROUTE_BRAKING`、`ROUTE_RECOVERING`、`ROUTE_FINISHED`）与六边形环岛子状态机（`HEXAGON_OFF`、`ENTERING`、`FOLLOWING`、`EXIT_CANDIDATE`、`EXITING`、`DONE`）。
     - `braking_planner.c`：已知路段距离减速包络规划（安全减速度 $120\text{ cm/s}^2$、加加速度限幅 $800\text{ cm/s}^3$）。
     - `odometry.c`：差速轮系里程计、TI12 四倍频与航向融合（Sinc 转向航向积分、编码器/IMU 双模）。
     - `speed_control.c`：双轮独立 PID 速度闭环与前馈 PWM 混流（量程 $500\text{ cm/s}$、满标尺 255）。
     - `pid.c`：含微分低通滤波与积分抗饱和的抗风移 PID。
   - 所有物理参数严格对齐 `motion_config.h`、`control_config.h`、`board_config.h`：
     - 控制周期：$5\text{ ms}$（$200\text{ Hz}$）
     - 轮轴中心间距（轮距）：$14.0\text{ cm}$
     - 轮径：$6.5\text{ cm}$
     - 灰度传感器中心前置距离：$24.0\text{ cm}$
     - 8 路传感器横向布局与线宽检测：支持实车 $2.5\sim 2.8\text{ cm}$ 胶带线宽。

2. **高保真赛道地图与尺寸图纸还原（画面铺满）**：
   - 尺寸严格按照 CAD 标注图纸构建：宽 $375.00\text{ cm} \times$ 高 $220.00\text{ cm}$。
   - 深度还原深蓝电路板底图风格（Deep Circuit Blue）：
     - 细密工程网格背景与白色高保真赛道导轨。
     - $x = 55\text{ cm}$ 处虚线赛道（$y \in [120, 220]$），模拟间歇丢线与过虚线循迹。
     - 右下角正六边形环岛（边长 $35.00\text{ cm}$，右顶点 $(345.00, 165.00)$，与竖直干线 $30^\circ$ 夹角衔接）。
     - 完整绘制 27 个电路元件符号（起点/终点 P 处电池电源、27 个途经电阻/二极管、三极管 NPN/PNP 符号）。
     - 完整 CAD 尺寸标注链（顶边 55/40/150/30/70/30、左侧 120/100、内部方框 80/40/40 等），可随时一键开启/关闭。
   - **画面铺满自适应**：窗口缩放自动计算最佳比例贴合视口，同时支持鼠标滚轮平滑缩放、左键自由平移与“视角跟随”小车跟踪。

3. **每次运行仿真时上传 `route_table.c`**：
   - 顶部导航栏提供显著的 **“📁 上传 route_table.c”** 按钮。
   - 支持全局拖拽上传文件（直接将 `.c` / `.h` 拖入浏览器即可）。
   - 内置强大的 `route_table.c` 解析器，自动识别并提取代码中的各个预设方案：
     - 方案 1：正式全元件路线（走虚线 + 走环岛，覆盖全部 27 个元件，共 30 步）
     - 方案 2：不走虚线，走环岛路线（30 步）
     - 方案 3：走虚线，不走环岛路线（25 步）
     - 方案 0：基础调试路线（4 步）
     - 用户上传的任意自定义 `const RouteStep route[] = { ... };` 表项与注释。
   - 提供弹窗式 **“📋 路径详情”** 抽屉，展示当前所有步的参数、路口上限、限速、角度与注释说明，仿真运行时高亮当前活动步！

4. **小车模型与实时调试遥测 HUD**：
   - 按照实际车体结构简单绘制：车体亚克力底板、左右独立驱动轮与橡胶胎痕、前置万向轮、中央 STM32 核心板与 TB6612 驱动模块。
   - 前置 8 路灰度传感器状态灯：车头实时点亮当前检测到白线的绿色探头（未触发为暗色），并画出前向航向指示向量与行驶轨迹发光尾迹。
   - 实时遥测仪表盘（HUD）：
     - 8 路光电探头状态灯与实时加权偏差 Position（$-7.0 \sim +7.0$）、白线掩码与分类。
     - 小车线速度、目标航速、左右轮实时速度与左右轮 PWM 指令（$0\sim 255$）。
     - 当前车体世界坐标 $(X, Y)$、累计行驶里程、仿真耗时。
     - 当前路径规划步序号、动作名称、FSM 状态与路口识别计数。

## 🚀 快速启动

### 1. 安装依赖
```bash
npm install
```

### 2. 启动本地开发服务
```bash
npm run dev
```
启动后终端将输出访问地址（如 `http://localhost:5173/`），在浏览器中打开即可开始仿真！

### 3. 构建发布版本
```bash
npm run build
npm run preview
```

### 4. 回归测试
```bash
npm test
```
覆盖启动确认、三/四/五路平滑分支、捕线后的 PID 反向纠偏、普通失线 400 ms/8 cm 停车、首两弯、Q4→Q6 的三种方案物理轨迹，以及超时恢复当帧清空临时出口轴。2026-11-06 修复说明和边界见 `car_stm32/docs/evidence/2026-11-06-q6-stop/README.md`；仿真器仍未采样元件图形，并且减速前伸量与 C 固件表长语义不同。

六边形入口回归（`tests/hexagon_entry.test.ts`）：C 与 TS 都不再在环岛接近段提前 `return`（此前会跳过速度环、保留制动帧的 `standby=false`，车辆滑行到停并超时），并且 8 路前探头先看到入口支路时，用完整支路包络中点 + 24 cm 前伸量定位环岛顶点，而不是用最后一个支路点提前起转。该回归验证左右镜像入口、入口速度门限和物理捕获；环岛内部逐边循迹和整圈路线仍在标定中。

## 🎮 操作指南

| 操作 | 对应快捷键 / 按钮 | 功能说明 |
| :--- | :--- | :--- |
| **运行 / 暂停** | `空格键` 或 `▶ / ⏸` | 启动或暂停物理仿真推进 |
| **单步步进** | `⏭ 单步` | 暂停状态下向前单步推进 $5\text{ ms}$（一个控制周期） |
| **复位起点** | `↺ 复位` | 小车瞬间回到初始发车点 $P(0, 120)$ 并朝向正北 |
| **调节倍速** | `0.2x` ~ `10x` | 选择 $0.2\sim 10$ 倍速加速仿真或慢动作分析循迹细节 |
| **画面铺满** | `⛶ 画面铺满` | 视口自动居中且填满当前浏览器窗口 |
| **缩放与平移** | 鼠标滚轮 / 鼠标拖拽 | 自由缩放赛道细节或拖动赛道视角 |
| **上传路径表** | `📁 上传 route_table.c` | 选择本地文件或拖入窗口，一键热替换路径 |
| **切换方案** | 顶部下拉菜单 | 一键在方案 0、1、2、3 之间无缝切换 |
| **显示切换** | 底部右侧复选框 | 勾选/取消勾选“视角跟随”、“尺寸标注”、“元件标记” |
